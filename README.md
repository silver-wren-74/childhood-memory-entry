Entry for the Make.fun competition **"Make the AI Judge Feel Nostalgic:
A Childhood Memory"**
([bounty page](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363)).

`main.py` writes one sentence — a single childhood memory, at most 280
characters — to `/output/entry.txt`:

> Every August evening my grandmother called us in from the yard by rattling
> the old biscuit tin of fried shallots, and we came running barefoot across
> the still-warm tiles, certain that summer, and she, would never end.

Run it the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
